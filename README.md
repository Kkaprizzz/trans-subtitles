# Trans Subtitles

Приложение для Linux и Windows: берёт видео или аудио, локально распознаёт русскую речь и делает оверлей с субтитрами
на всю длину ролика. Оверлей накладывается поверх видео в монтажной программе.

- Распознавание локально, без интернета и облаков: GigaAM v3 (русский) и Whisper (small, turbo).
- Три режима: слово за словом, пословная подсветка, печатная машинка.
- Настройка шрифта, цветов, обводки, тени, подложки, положения и анимации.
- Экспорт: MOV с альфа-каналом (Animation, ProRes 4444) или MP4 на зелёном фоне. Можно добавить звук исходника.
- Редактор слов: правка текста и времени прямо на видео и в списке, отмена, автосохранение.

## Запуск из исходников

Нужны Node.js 22+ и git.

```bash
npm install
npm start
```

Для Whisper нужен бинарник whisper.cpp: положи сборку `whisper-cli` в `resources/whisper/<платформа>/`
(`linux-x64`, `win-x64`) или укажи путь в переменной `WHISPER_CLI`. В релизах он идёт внутри установщика.
Модели скачиваются при первом выборе в самом приложении.

## Сборка

```bash
npm run pack   # быстрая сборка в папку release/ без установщика
npm run dist   # AppImage (Linux) или установщик NSIS (Windows)
```

Релизы собирает GitHub Actions по тегу `v*` (`.github/workflows/release.yml`). Приложение само проверяет обновления.

## Проверки

```bash
npm run typecheck
npm test                                   # юнит-тесты чистой логики
node scripts/ci-smoke.mjs <собранное приложение>   # дымовой тест сборки: распознавание и рендер
```

В CI дымовой тест запускается на Linux и Windows перед упаковкой установщика.
